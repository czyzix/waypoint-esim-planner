
# Waypoint - eSIM planner

## Short Summary

Waypoint eSIM Planner is a simple app that helps travelers find the best eSIM plan for their trip based on their travel preferences.

The main goal of this project wasn't just the app itself, it was an excuse to get more hands-on with React and experiment with an Agentic Development workflow using Cursor. Most of the code was generated by AI, while I focused on code reviews, making improvements, fixing issues, and keeping the overall code quality in check.

I also tried writing a simple project spec and let AI implement most of the features from it. As a bonus, I even built a small backend flow with AI, which was something I hadn't really done before. Overall, this project was a fun way to reinforce my React knowledge, explore AI-assisted development, and see how far this workflow can go.

# How to Launch Locally

## Prerequisites

- [Node.js](https://nodejs.org/) **20+** (`node -v` to check)
- npm (included with Node)

## 1. Install dependencies

From the repo root:

```bash
cd backend
npm install

cd ../frontend
npm install
```

## 2. Start the backend

In one terminal:

```bash
cd backend
npm run dev
```

API runs at **http://localhost:3001** (optional: set `PORT` env var to change it).

## 3. Start the frontend

In a second terminal:

```bash
cd frontend
npm run dev
```

App runs at **http://localhost:5173**. Vite proxies `/api` requests to the backend.

## 4. Open the app

Visit **http://localhost:5173** in your browser. Keep both terminals running while you use the wizard.

## Optional

- **Frontend tests:** `cd frontend && npm test`
- **Typecheck:** `npm run typecheck` in `backend` or `frontend`

## Production (API)

On the backend host set `CORS_ORIGIN` to your frontend URL (e.g. `https://waypoint-demo-pied.vercel.app`). See `backend/.env.example`.

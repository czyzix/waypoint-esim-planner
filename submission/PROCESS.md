## Creating Waypoint - Travel Connectivity Assistant

### 🤔 Idea

First things first - every app starts with an idea. 
After reading the README.md I've started to think about an app which I would use myself during preparation for a trip.
When we are talking about connectivity my biggest problems were always:

- should I buy just one plan for me and friend/s or separate plans?
- how much data am I going to use anyway?
- what if I want to visit multiple countries?

Waypoint is an anwser to all those questions. I've decided to create assistant which will help me calculate my data usage based on my habits and travel plans.
Ok, but did i used any AI on this step? 🫣

Of course!

I've used ChatGPT to talk about how I want my app to workand feel.

> I want to create an eSIM assistant app which will help user find the best plan for his trip plans and my data usage habits. I want the user to feel like we guide it through the process, to feel save. Can you give me some tips how to achieve that "feel" in my app?

> Can you create a list of 10 potential names for my app?

Including such prompts I was able to create a vision of app in my head, how I exactly want it to look, what user should see, and what to avoid.
